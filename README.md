# Pixelle-Studio - README

## Project Overview

This is an intelligent workflow system based on the **OpenAI Agents SDK + Skills + MCP Tools** architecture. The system uses a single Agent architecture, implementing multi-turn conversations and code execution through standard Tool Calling mechanisms.

### Core Features

- **Standard Tool Calling**: Uses OpenAI Agents SDK's `@function_tool` decorator to define tools, following OpenAI specifications
- **Progressive Skill Loading**: Skills system supports on-demand loading of domain knowledge, preventing Context Window overflow
- **Streaming Output**: Uses `Runner.run_streamed()` for real-time streaming responses
- **Code Sandbox Execution**: Safely executes Python code generated by the Agent
- **MCP Tool Integration**: Supports connecting to external MCP servers for tool invocation

## Architecture Design

### Architecture Evolution

```
v1.0 (Legacy): LLM Response → Regex parse [LOAD_SKILL:] / ```python``` → Manual dispatch execution
v2.0 (Current): LLM with tools → tool_calls field → Auto execute → tool message → LLM continues
```

## Tool Calling System

### 5 Core Tools

| Tool | Function | Parameters |
|------|----------|------------|
| `load_skill` | Load skill documentation (SKILL.md) | `skill_name: str` |
| `read_skill_file` | Read files in skill directory | `skill_name: str, file_path: str` |
| `list_skill_tree` | List skill directory structure | `skill_name: str` |
| `execute_code` | Execute Python code | `code: str` |
| `list_mcp_tools` | Discover available MCP tools | None |

### Tool Definition Example

```python
from agents import function_tool, RunContextWrapper

@function_tool
async def load_skill(ctx: RunContextWrapper[AgentContext], skill_name: str) -> str:
    """Load skill documentation (SKILL.md) for domain-specific guidance."""
    context = ctx.context
    skill_content = context.skill_loader.read_skill(skill_name, context.user_id)
    return skill_content or f"Skill '{skill_name}' not found"
```

### Agent Execution Flow

```python
from agents import Agent, Runner

agent = Agent(
    name="SkillAgent",
    instructions=system_prompt,
    tools=[load_skill, read_skill_file, list_skill_tree, execute_code, list_mcp_tools],
    model="gpt-4o",
)

# Streaming execution
result = Runner.run_streamed(agent, input=messages, context=agent_context)

async for event in result.stream_events():
    # Handle tool_call, tool_result, response and other events
    yield convert_event(event)
```

## Skills System

### Progressive Loading Mechanism

1. **Level 1 (Metadata)**: Scan `skills/` directory, extract SKILL.md Frontmatter
2. **Level 2 (Documentation)**: Agent calls `load_skill` to load full documentation
3. **Level 3 (Files)**: Agent calls `read_skill_file` to read specific files

### Skill Directory Structure

```
skills/
├── default/           # Default skills
│   ├── xlsx/

│   └── ...
└── <user_id>/         # User-defined skills
    └── ...
```

## Quick Start

### 1. Environment Configuration

```bash
# Set environment variables
export OPENAI_API_KEY="your-api-key"
export OPENAI_BASE_URL="https://api.openai.com/v1"  # Optional
export LLM_MODEL="gpt-4o"  # Optional, defaults to gpt-4o
```

### 2. Start Backend

```bash
cd backend
uv sync  # Install dependencies on first run
./start_server.sh
```

### 3. Start Frontend

```bash
cd frontend
npm install  # First run only
npm run dev
```

### 4. Access Application

Open browser and visit: http://localhost:3000
